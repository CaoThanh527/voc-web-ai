# 🚀 VOC Web AI

> **VOC Web AI** là dự án thiết kế và phát triển website được xây dựng nhằm thực hành các kiến thức về **Web Development**, giao diện người dùng và quản lý mã nguồn bằng **Git/GitHub**.

---

## 📌 Giới thiệu

VOC Web AI là một website được phát triển trong quá trình học tập môn **Thiết kế Web**.

Dự án tập trung vào việc xây dựng giao diện website bằng các công nghệ web cơ bản, đồng thời áp dụng quy trình làm việc với **Git và GitHub** để quản lý mã nguồn, phân chia công việc và cập nhật phiên bản.

---

## 🎯 Mục tiêu dự án

* Xây dựng giao diện website trực quan, dễ sử dụng.
* Thực hành HTML, CSS và JavaScript.
* Rèn luyện kỹ năng thiết kế giao diện Web.
* Làm quen với Git và GitHub.
* Thực hành làm việc với Branch trong Git.
* Quản lý phiên bản và lịch sử thay đổi của source code.
* Áp dụng quy trình phát triển website trong môi trường làm việc nhóm.

---

## 🌿 Git Branch

Dự án sử dụng Git Branch để quản lý các phiên bản và công việc của từng thành viên.

Các branch hiện có:

```text
main
QMinh
...
```

### Branch `QMinh`

Branch `QMinh` được sử dụng để phát triển và cập nhật các nội dung do QMinh thực hiện.

Quy trình làm việc:

```text
Code
  ↓
git add
  ↓
git commit
  ↓
git push
  ↓
GitHub
```

## 💻 Cài đặt và chạy dự án

### 1. Clone repository

```bash
git clone https://github.com/CaoThanh527/voc-web-ai.git
```

### 2. Di chuyển vào thư mục dự án

```bash
cd voc-web-ai
```

### 3. Mở project bằng Visual Studio Code

```bash
code .
```

### 4. Chạy website

Mở file:

```text
index.html
```

bằng trình duyệt hoặc sử dụng extension **Live Server** trên Visual Studio Code.

---

## 🔄 Quy trình cập nhật code

Trước khi bắt đầu làm việc:

```bash
git pull
```

Sau khi hoàn thành thay đổi:

```bash
git add .
```

Tạo commit:

```bash
git commit -m "Update website"
```

Đẩy code lên GitHub:

```bash
git push
```
