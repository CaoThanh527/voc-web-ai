Tóm Tắt Bản Thân

Tôi là một kỹ sư lập trình giao diện Web (Front-End Developer) với đam mê xây dựng những trải nghiệm số mượt mà, tối ưu hiệu năng tải trang và tuân thủ nghiêm ngặt các tiêu chuẩn quốc tế về ngữ nghĩa (Semantic HTML5), khả năng tiếp cận cho mọi người (Web Accessibility - WCAG) cùng kỹ thuật tối ưu hóa công cụ tìm kiếm (Technical SEO).

Mục tiêu nghề nghiệp: Đồng hành cùng doanh nghiệp phát triển các ứng dụng web quy mô lớn, đảm bảo khả năng bảo trì cao, tốc độ tải vượt trội và trải nghiệm thân thiện với người dùng.

Kỹ Năng Chuyên Môn

Dưới đây là các công nghệ và kỹ năng cốt lõi tôi sử dụng trong quá trình phát triển web:

1. Nền Tảng Front-End Cốt Lõi (Core Web Technologies)

  • HTML5 & Semantic Web: Xây dựng khung trang web chuẩn cấu trúc W3C, tối ưu Accessibility (ARIA) và SEO On-page.
  • CSS3: Làm chủ Flexbox, CSS Grid, Responsive Web Design (Mobile-First), CSS Variables.
  • JavaScript (ES6+): Lập trình hướng đối tượng, bất đồng bộ (Promises, Async/Await), DOM Manipulation, Event Loop.
  • TypeScript: Quản lý kiểu dữ liệu chặt chẽ, tối ưu code dự án lớn và hạn chế lỗi runtime.

2. Thư Viện & Frameworks Hiện Đại

  • React.js: Component Lifecycle, Custom Hooks, State Management (Redux Toolkit, Zustand).
  • Next.js: Server-Side Rendering (SSR), Static Site Generation (SSG), tối ưu SEO toàn diện.
  • Tailwind CSS: Xây dựng giao diện nhanh chóng theo phương pháp Utility-first.

3. Công Cụ & Tiêu Chuẩn Chất Lượng (Best Practices)

  • Version Control: Git, GitHub Flow, Code Review, CI/CD cơ bản.
  • Hiệu năng & SEO: Tối ưu Core Web Vitals, Google Lighthouse, Lazy Loading, nén tài nguyên.
  • Web Accessibility (A11y): Đạt chuẩn WCAG 2.1 AA, kiểm thử bằng Screen Reader và điều hướng bàn phím.

Dự Án Nổi Bật

Tuyển tập các dự án tiêu biểu minh chứng cho năng lực lập trình và tư duy phát triển sản phẩm:

Dự án 1: Bảng Điều Khiển Tài Chính Phân Tích Nexus (Nexus Dashboard)

Thời gian thực hiện: Tháng 10/2025 – Tháng 01/2026

Công nghệ sử dụng: React.js, TypeScript, Chart.js, Tailwind CSS.

Mô tả dự án: Hệ thống Dashboard hỗ trợ quản lý dòng tiền doanh nghiệp với khả năng hiển thị biểu đồ biến động tài chính theo thời gian thực, lọc dữ liệu nhiều chiều và xuất báo cáo tự động.

Kết quả đạt được: Tốc độ tải trang dưới 1.2s, điểm Google Lighthouse đạt 97/100, hỗ trợ giao diện Dark/Light mode và điều hướng bàn phím 100%.
